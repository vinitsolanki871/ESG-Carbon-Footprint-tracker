# ESG-Carbon-Footprint-tracker
A production-grade ESG Carbon Footprint Tracker built with Streamlit. Features automated Scope 1 &amp; 2 carbon accounting (CEA/MoPNG factors), multi-layer PyDeck geospatial mapping, real-time data filtering, dynamic mitigation insights, and a predictive Net-Zero trajectory simulator aligned with SBTi 1.5°C pathways. 🌿
